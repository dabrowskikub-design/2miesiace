# NASZA HISTORIA — wersja Bauhaus

## Pliki
- index.html — struktura strony
- style.css — wygląd i animacje
- script.js — zagadki i treść

## Jak personalizować
Otwórz `script.js` i edytuj wyłącznie blok `CONFIG` na samej górze.

Możesz zmienić:
- imię dziewczyny
- swoje imię
- intro
- 7 zagadek
- odpowiedzi
- podpowiedzi
- wspomnienia
- zdjęcia
- końcowy list

### Zdjęcia
Utwórz folder `assets`, wrzuć np. `poznanie.jpg`, a następnie wpisz:
photo: "assets/poznanie.jpg"

### Typy zagadek
- type: "date" — wybór daty
- type: "word" — wpisanie słowa
- type: "yesno" — TAK / NIE

## Uruchomienie
Najprościej otworzyć `index.html` w przeglądarce.

Do publikacji możesz wrzucić cały folder na dowolny hosting statyczny.
